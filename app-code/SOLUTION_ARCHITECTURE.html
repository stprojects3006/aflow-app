Spring PetClinic Solution Architecture

Comprehensive architecture for the PetClinic application, QueueIt integration, monitoring, and deployment.

1. Overview

Stack: Spring Boot, Maven, Docker, MySQL/Postgres/H2, Prometheus, Grafana, Nginx, AWS (optional), QueueIt integration, K6 load testing.
  • Modular Java backend (Spring Boot, Maven)
  • Multiple database support (H2, MySQL, Postgres)
  • QueueIt integration for queue management and protection
  • Comprehensive monitoring (Prometheus, Grafana, custom dashboards)
  • Containerized deployment (Docker Compose, Nginx reverse proxy)
  • Cloud-ready (AWS ECS, Fargate, S3, CloudWatch, etc.)
  • DevOps automation scripts for build, deploy, and monitoring

  • Nginx: Reverse proxy for routing, SSL termination, and static content
  • PetClinic App: Spring Boot application, exposes REST and web endpoints
  • Databases: MySQL, Postgres, or H2 (dev/test)
  • QueueIt: Cloud-based queue management for protected routes
  • Prometheus: Metrics scraping from PetClinic and infrastructure
  • Grafana: Visualization and alerting (5+ dashboards)
  • K6: Load testing with IP diversity (AWS ECS tasks)

3. Application Structure

  • src/main/java/org/springframework/samples/petclinic/
    • model/: Domain models (Owner, Pet, Vet, etc.)
    • owner/, vet/: Controllers, repositories, business logic
    • integration/: QueueIt integration controller, settings
    • system/: App config, cache, web config, welcome, crash
    • config/: RestTemplate and other beans
  • src/main/resources/
    • application.properties: DB, QueueIt, metrics, logging
    • db/: SQL scripts for H2, MySQL, Postgres
    • templates/: Thymeleaf HTML templates
    • static/: CSS, images, fonts
  • aws-ec2/: AWS deployment scripts, Docker Compose for AWS, Nginx config
  • grafana-dashboards/: 5+ JSON dashboards for Grafana
  • load-test/: K6 load test scripts, error generators
  • Dockerfile: Spring Boot app containerization
  • docker-compose.*.yml: Compose files for app and infra
  • deploy*.sh: Build, deploy, and monitoring automation

4. Deployment & Networking

  • Local: docker-compose.infra.yml (MySQL, Postgres, Prometheus, Grafana, Nginx), docker-compose.app.yml (PetClinic app)
  • Cloud: aws-ec2/ scripts for ECS, Fargate, CloudFront, S3, etc.
  • Nginx: Handles SSL, reverse proxy, static content, and routing to app and dashboards
  • Networking: All services on petclinic-net Docker network; AWS VPC/subnets for cloud
[User] -> [Nginx] -> [PetClinic:8080]
                   -> [Grafana:3000]
                   -> [Prometheus:9090]
                   -> [DB:3306/5432]

5. QueueIt Integration

  • Official QueueIt connector (Maven dependency)
  • Protected routes (e.g., /owners/new) trigger 302 redirects to QueueIt
  • Integration controller for health, config, queue, validation, and test endpoints
  • Configuration in application.properties (customer ID, event ID, secret key, API key)
  • Metrics for QueueIt API calls, redirects, errors, and health
[User] -> [Nginx] -> [PetClinic] --(protected route)--> [QueueIt Cloud]

6. Monitoring & Observability

  • Prometheus: Scrapes metrics from PetClinic (/actuator/prometheus), Nginx, DBs
  • Grafana: 5+ dashboards (QueueIt Integration, Error Tracking, Request Volume, App HTTP Traffic, PetClinic Traffic)
  • Custom Metrics: QueueIt API, filter, redirects, validation, error rates, IP tracking
  • Alerting: Prometheus alert rules, Grafana notifications
[Prometheus] <--- [PetClinic: /actuator/prometheus]
            <--- [Nginx, MySQL, Postgres]
[Grafana] <--- [Prometheus]

7. Load Testing & IP Diversity

  • K6: Load testing with scripts targeting protected and public routes
  • IP Diversity: Multiple ECS tasks, each with unique AWS public IP (Fargate, VPC, subnet)
  • Scripts: run-10-vu-tasks.sh, run-enhanced-queueit-test.sh
  • Metrics: Unique IPs, redirect rates, error rates, response times
[K6 ECS Task 1] (IP 3.x.x.1) -> [Nginx] -> [PetClinic]
[K6 ECS Task 2] (IP 3.x.x.2) -> [Nginx] -> [PetClinic]
...

8. DevOps & Automation

  • Shell Scripts: deploy.sh, deploy-app.sh, deploy-infra.sh, deploy-grafana-dashboards.sh
  • CI/CD: Maven/Gradle build, Docker image build, test, and deploy
  • Cloud Automation: aws-ec2/ scripts for ECS, Fargate, CloudFront, S3
  • Health Checks: Automated health checks for all services
  • Dashboard Import: Automated Grafana dashboard import

9. Security & Best Practices

  • Network isolation (Docker network, AWS VPC/subnets)
  • Secrets managed via environment variables or config files
  • Role-based access for AWS resources
  • SSL termination at Nginx (optional)
  • Database credentials not hardcoded in code
  • Comprehensive logging and error tracking
