Queue-it Integration Technical Architecture

Comprehensive Technical Documentation with Flow Diagrams and Integration Details

🏗️ System Overview

This document provides a comprehensive technical architecture overview of the Queue-it integration within the Spring PetClinic application, deployed on AWS EC2. The integration enables virtual queuing capabilities with real-time monitoring and load testing support.

🎯 Core Components

  • Nginx: SSL termination & reverse proxy
  • Spring PetClinic: Main application with Queue-it integration
  • Queue-it Cloud: Virtual queuing service
  • Monitoring Stack: Prometheus + Grafana

🔧 Integration Features

  • Token Validation: Real-time queue token verification
  • Queue Management: User queuing and session handling
  • Health Monitoring: Endpoint health checks
  • Metrics Collection: Comprehensive observability

// QueueItIntegrationController.java - validateQueueToken method public ResponseEntity<String> validateQueueToken(String body) { Timer.Sample sample = Timer.start(meterRegistry); meterRegistry.counter("queueit_validate_total").increment(); try { String url = queueItSettings.getBaseUrl() + "/validate"; HttpHeaders headers = buildHeaders(); headers.set("customer-id", queueItSettings.getCustomerId()); headers.set("secret-key", queueItSettings.getSecretKey()); headers.set("Content-Type", "application/json"); HttpEntity<String> entity = new HttpEntity<>(body, headers); ResponseEntity<String> response = restTemplate.postForEntity(url, entity, String.class); meterRegistry.counter("queueit_api_success_total", "operation", "validate").increment(); return ResponseEntity.status(response.getStatusCode()).body(response.getBody()); } catch (Exception e) { meterRegistry.counter("queueit_api_errors_total", "operation", "validate").increment(); return ResponseEntity.status(502).body("{\"error\":\"Queue-it API error: " + e.getMessage() + "\"}"); } finally { sample.stop(Timer.builder("queueit_validate_duration").register(meterRegistry)); } }

🔧 Troubleshooting Guide

🚨 Common Issues

  • API Timeouts: Check network connectivity and Queue-it service status
  • Authentication Errors: Verify API keys and customer ID
  • SSL Certificate Issues: Check Let's Encrypt certificate renewal
  • High Error Rates: Monitor Grafana dashboards for patterns
  • Performance Degradation: Check resource utilization

🔍 Debugging Tools

  • Grafana Dashboards: Real-time metrics visualization
  • CloudWatch Logs: Application and access logs
  • Queue-it Health Endpoint: /integration/queueit/health
  • Integration Test UI: /integration/queueit/
  • Nginx Access Logs: Request/response logging

📋 Troubleshooting Steps:

  1. Check Application Health: Verify PetClinic is running and responding
  2. Validate Queue-it Connectivity: Test /integration/queueit/health endpoint
  3. Review Metrics: Check Grafana dashboards for error patterns
  4. Examine Logs: Review CloudWatch logs for error details
  5. Test Integration: Use /integration/queueit/validate with test tokens
  6. Verify Configuration: Check QueueItSettings and API credentials
